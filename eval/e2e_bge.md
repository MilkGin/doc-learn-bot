# 端到端闭环实验：bge-m3 修复检索后的 RAG 答案正确率（含 TOP_K 4→8 实测）

日期：2026-10-31。脚本 `eval/e2e_bge.py`（可重跑），原始回答 `eval/e2e_bge_raw.jsonl`，判卷 `eval/e2e_bge_judge.csv`。
生成器与 longctx 实验完全一致（qwen2.5:7b，num_ctx=8192，同一 prompt 模板），**唯一变量是检索配置**。
判卷：GLM-5.3-Flash（与生成器异源；与出题同源的偏差已在 longctx 报告声明，此处同样适用）。
判分口径同 `longctx_vs_rag.md`：对 / 部分 / 错 / 正确拒答；answerable 的拒答不得分。

## 2. 三个结论

**结论 1：预测验证——修好检索后，RAG 在正确率上也反超了全文塞入。**
同一生成器下：nomic-RAG 30.8% → bge-RAG 76.9%（+46.1pt）→ 超过全文塞入的 69.2%。至此离线路线的最终答案完备：**RAG 在正确率、延迟（1.5s vs 10.8s）、成本（1,056 vs 16,246 token）三个轴上全部胜出，且不受 16,386 token 上下文硬上限约束**。`longctx_vs_rag.md` 的"修检索比修容量便宜一个数量级"由预测变为实测。

**结论 2：检索质量直接传导为答案质量。**
分层 50 题上，检索 recall@5=0.795 对应端到端对率 70.7%（含部分 80.5%）；对照 nomic 时代检索 0.325 对应 30.8%。检索指标与端到端正确率同向、幅度相当——继续优化检索（rerank 等）仍是最便宜的提升路径。

**结论 3：TOP_K 4→8 实测有效（P0-3 配置 C 的端到端实测值）。**
同 50 题：对率 70.7%→80.5%（+9.8pt），错误 8→5，**零新增错误**——担心的"更多干扰块带偏生成"在这套题上没有发生一次。代价：延迟中位 2.3s→3.8s、prompt token 1,530→2,914（仍在 8192 窗口内宽裕）。检索侧解释：bge 的 recall@10=0.884 比 recall@5=0.795 多覆盖 9pt 的黄金块，把 top5-10 的正确块放进上下文直接转化为答案。

## 3. 剩余错误分析（B 路线 8 错 + 4 部分）

| 错误类型 | 题目 | 根因 |
|---|---|---|
| 检索未命中（3） | 售后保修起算、渠道来源、配件退货规则（3 题） | bge 也有 recall 盲区（recall@10 仍有 11.6% 缺口） |
| 相邻主题混淆（2） | 同系列产品参数串台（答出另一型号参数并编造数值）、退款流程与退差价流程混淆 | 问法与"最相似但不是答案"的块距离过近——**这正是 rerank / 更强判别模型的靶子** |
| 多跳一半（2 部分 + 1 部分） | 充电时长数字错（1h10m vs 1h20m）、只答出一种返航规则、结论对但引用了错误流程 | 多跳第二证据块不稳 |
| 硬负例混淆（1） | 相近数值门槛的规则互相压过（正确规则被干扰规则挤掉） | top-4 内正确块被干扰块挤掉；top-8 修复（C 路线答对） |

## 4. 口径与局限

- 17 题为 longctx 原题集（品牌A 域），50 题为全语料分层抽样（按类型等比：factoid 28 / 难负例 7 / 多跳 6 / 无答案 9，类型内按 id 等距，确定性可复现）。
- 对率不含"部分"；含部分的口径已同时给出。no_answer 拒答 13/13（A 4 + B/C 9）全部正确。
- 单次实验、GLM 判卷与出题同源的偏差同前；差距量级（30-50pt）远大于判卷噪声。
